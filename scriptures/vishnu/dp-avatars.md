# Divya Prabandham references: avatar and temple-image stories

Written in session 1 (2026-10-26) by a research pass over divyaprabandham.koyil.org. Machine-readable copy: `dp/avatars.json`.

**Confirmed** = the page was opened and names the story. **Not confirmed** = only seen in a search snippet or cited by another page's commentary. Numbers are prabandham + decad.pasuram as the page states them; none of the pages gave the continuous 1-4000 number. First words are the page's transliteration (Tamil script given where the page showed it).

Correction: earlier project notes said 'Periya Thirumozhi 3.5.1' for Gajendra; the page is Thiruvaimozhi (Nammazhwar) 3.5.1.

Gaps: no Mohini verse found; no Divya Prabandham verse found for Kurma alone (only 3.3.7 listing three forms); Kanchi has only Periya Thirumozhi 1.5.4 (thiruvUragam named in the word meanings), nothing opened for Thiruvehka or the Ulagalandha deity itself.

Hosts: the site's coverage is partial (some decads are not yet posted), so absence there is not absence in the text.
